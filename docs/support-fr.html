Questions fréquentes

Pourquoi les écarts entre les événements sont-ils tous différents ?

Yeoul espace les événements selon le temps réellement écoulé entre eux. Tous les écarts utilisent la même échelle : trois jours et cinq jours sont donc dessinés à 3:5. Les événements très proches gardent une distance minimale pour ne pas se chevaucher, et les très longues périodes se replient en pointillés avec la durée réelle, par exemple « 2 ans 4 mois ».

Je ne vois pas les photos prises ce jour-là.

La recherche de photos par date nécessite l’accès à votre photothèque. Allez dans Réglages → Yeoul → Photos et autorisez l’accès. Yeoul cherche les photos prises de minuit à minuit à cette date, dans le fuseau horaire de votre appareil. Si vous préférez ne pas donner l’accès, utilisez le bouton Chercher moi-même juste en dessous pour choisir dans votre photothèque.

Qu’est-ce qu’une frise par tag ?

Touchez le tag d’un événement et Yeoul réunit tous les événements portant ce tag, toutes vos frises confondues, en une seule frise. Les tags que vous consultez souvent peuvent être enregistrés pour rester dans votre liste.

Puis-je ajouter un événement sans ouvrir l’app ?

Oui. Dans l’app Raccourcis ou avec Siri, utilisez Enregistrer un événement : choisissez une frise, donnez un titre à l’événement, et il est enregistré à l’heure actuelle, sauf si vous choisissez une date.

Puis-je voir mes données sur d’autres appareils ?

Les appareils connectés à iCloud avec le même Apple Account se synchronisent automatiquement, y compris l’app Mac. Vérifiez qu’iCloud est activé dans Réglages → Apple Account → iCloud. Selon votre réseau, les modifications peuvent mettre un peu de temps à apparaître.

Comment supprimer mes données ?

Balayez une frise vers la gauche dans la liste, ou touchez Modifier, pour la supprimer. Supprimer une frise supprime aussi les événements qu’elle contient. Les données restantes dans iCloud peuvent être supprimées dans Réglages → Apple Account → iCloud → Gérer le stockage.

Mes données sont-elles envoyées au développeur ?

Non. Vos données et vos photos sont stockées uniquement sur vos appareils et dans votre propre iCloud ; le développeur ne peut pas les voir. Yeoul envoie des statistiques d’usage anonymes et des rapports d’incident qui ne contiennent aucun de vos contenus. Consultez la politique de confidentialité pour en savoir plus.
